## Desktop release acceptance — still required

This workspace is Linux with a virtual X display, not a real Omarchy session.
Before promoting a release, check on an Omarchy machine:

1. Install the package, launch from the application menu, and confirm icon/window
   grouping under Hyprland. Upgrade an existing 0.1.0 install with a saved game.
2. Play draw-one and draw-three by click, drag and keyboard. Confirm long columns
   remain usable tiled at 800 × 600, and test actual fractional display scaling.
3. Switch real Omarchy themes, including during a drag. Lock a theme, restart,
   then resume following. Import the team's SVG/PNG through the desktop portal.
4. Suspend/resume, switch workspaces and reopen after a clean exit. Confirm the
   timer and saved table behave as expected.
5. Check screen-reader announcements and focus order through AccessKit on the
   target desktop. Headless widget metadata tests do not establish AT-SPI behavior.
6. Measure startup, memory and idle CPU on the target hardware. Local virtual
   display measurements do not establish an Omarchy performance budget.

No real Omarchy, fractional Wayland scaling, portal UI or screen-reader pass is
claimed. No public release or distribution submission has been made.
